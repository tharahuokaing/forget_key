# 🎰 Cyber HUD & High-Roller Vault System

An interactive, responsive Cyberpunk-themed Head-Up Display (HUD) featuring a 3-step Security Key Recovery modal, real-time balance tracking, and custom CSS-animated running LED gradient borders.

## ✨ Features

* 💎 **Cyberpunk HUD Header:** Sticky navigation bar displaying user credits, VIP tier badges, and action triggers.
* ⚡ **Animated LED Running Card Borders:** Pure CSS `conic-gradient` animation driving running border effects around modals and status panels.
* 🔑 **3-Step Security Key Recovery:** Multi-step modal walkthrough covering:
  1. Identity / Email input
  2. 6-Digit PIN verification with custom auto-tabbing interface
  3. Security passcode reset
* 🔐 **Authentication Overlay:** Built-in modal handling for fast tab-switching between Login and Registration forms.
* 📱 **Fully Responsive:** Adapts smoothly across mobile viewports, tablets, and desktop displays.

## 🛠️ Project Structure

├── index.html        # Main DOM structure, HUD components & modal overlays
├── style.css         # Unified CSS design system, LED animations, & modal layouts
├── auth-system.js    # JavaScript controller for Login/Register modal toggles
└── forgot-key.js     # JavaScript controller for the 3-step recovery flow
